# 历史归档

此目录包含历史过程文件，仅供内部参考，不影响项目功能。

## 归档内容

- `agent-*-review.md` — 历史 Agent 评审记录（alpha/beta/gamma 等多轮迭代）
- `stirling-pdf-*.md` — Stirling PDF 项目盲测系列（v1-v7 多版本对比）
- `sample-blind-test-*.md` — 样本项目盲测系列（React/Vue/Mall/TypeORM 等）
- `v8-issues-fix-report.md` / `v9-improvement-report.md` — 早期迭代改进报告

## 为什么归档

这些文件记录了项目开发过程中的迭代历史，对理解设计决策有参考价值，
但不属于面向用户的核心文档。归档后：
- docs/ 根目录保持整洁，核心文档一目了然
- 历史文件仍可查阅，不丢失
- 新贡献者不会被大量过程文件干扰
