### 预编译机制

规则引擎采用预编译机制，将 Markdown 规则文件编译为缓存格式，提升加载速度。

**完整流程图**：

```

│  预编译阶段（人触发）                                                 │
│                                                                     │

│  │  人编辑 Markdown 规则         │  如 security/sql-injection.md    │
│  │  写自然语言 + 违规示例 +      │  包含 ```yaml 元数据             │
│  │  ```pattern 检测模式          │  和 ```pattern 代码块            │
│  └──────────────┬───────────────┘                                   │
│                 ↓                                                   │
│  ┌──────────────────────────────┐                                   │

│  └──────────────┬───────────────┘                                   │
│                 ↓                                                   │
│  ┌──────────────────────────────┐                                   │
│  │  计算 SHA256 hash            │  对每个 .md 文件计算 hash        │
│  └──────────────┬───────────────┘                                   │
│                 ↓                                                   │
│            ┌────hash 变化?────┐                                     │

│           │           │  - cwe, owasp 元数据         │               │

## 正确示例

```java

ps.setString(1, userId);
ps.execute();
